# portfolio-website

A personal portfolio website built using HTML and CSS.

## Features

* Responsive design
* About section
* Projects section
* Contact section
* Clean and modern UI

## Technologies Used

* HTML
* CSS

## How to Run

1. Clone the repository

```bash
git clone https://github.com/prapti504/portfolio-website.git
```

2. Open the project folder

```bash
cd portfolio-website
```

3. Open `index.html` in your browser
